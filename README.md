Sea View - 2D Computer Graphics Scene

Hello, Welcome to my computer graphics project repository. This is a real-time, animated 2D coastal scenery application that I built from scratch using C++, OpenGL (GLUT), and the Windows Multimedia API.

I wanted to create something peaceful yet visually dynamic, so the project features a fully automated day-night cycle, custom mathematical color blending, and relaxing beach vibes.

What's Going On in the Scene:

* Smooth Day-to-Night Transitions: The world doesn't just snap from light to dark. It gradually shifts through gorgeous color palettes for the sky, ocean, and sand depending on the time of day.
* Living Celestial Bodies: Watch the sun smoothly transition into the moon complete with a glowing halo effect, and keep an eye out for twinkling stars when night falls.
* Animated Coastal Life:
* The Ocean: Features gentle, rolling waves, shimmering light reflections from the sun and moon, and realistic foam crashing onto the shoreline.
* Sailing Boats: Boats cruise back and forth across the water with a natural bobbing motion to simulate waves.
* Birds: Flocks of birds glide across the horizon during the daytime.


* Hand-Crafted Scenery: I designed detailed vector-style elements including palm trees, lounge chairs, and striped beach umbrellas to give it that cozy summer feel.
* Atmospheric Sound: Included background wave audio (wave.wav) to bring the whole beach atmosphere together.

Interactive Controls:

You can control the time of day on the fly while running the program:

* Press 1 to instantly jump to Daytime
* Press 2 to switch to a warm Sunset
* Press 3 to switch to a starry Night
* Press ESC to close the application

Running the Project:

If you want to spin this up on your own Windows machine:

1. Make sure you have a C++ environment set up with OpenGL and FreeGLUT.
2. Open the source file in your favorite IDE like Code::Blocks, Dev-C++, or Visual Studio.
3. Make sure your linker includes the standard graphics libraries along with winmm.lib for the audio.
4. Optional: Drop a wave.wav file into your project folder if you want the ocean sounds to play.
5. Compile, run, and enjoy the view!
